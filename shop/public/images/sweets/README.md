# Product Images / মিষ্টির ছবি

Place your sweet photos in this directory: `shop/public/images/sweets/`.

### Recommended Specifications:
- **Format:** JPG, PNG, or WebP
- **Dimensions:** 800x600 px or 600x600 px (Square / 4:3)
- **File size:** Under 300 KB for fast loading

### Example Filenames:
- `rasmalai.jpg` -> URL: `/images/sweets/rasmalai.jpg`
- `chomchom.jpg` -> URL: `/images/sweets/chomchom.jpg`
- `bogra-doi.jpg` -> URL: `/images/sweets/bogra-doi.jpg`
- `rosogolla.jpg` -> URL: `/images/sweets/rosogolla.jpg`
- `kacha-golla.jpg` -> URL: `/images/sweets/kacha-golla.jpg`
- `motichur-laddu.jpg` -> URL: `/images/sweets/motichur-laddu.jpg`
- `kaju-barfi.jpg` -> URL: `/images/sweets/kaju-barfi.jpg`

When an `imageUrl` is set on a product in the database, the showcase automatically renders the photo on the product card and in the details modal. When no image is assigned, it renders a clean, modern typographic card.
